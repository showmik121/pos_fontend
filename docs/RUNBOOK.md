# রানবুক: ফ্রন্টএন্ড (Netlify)

কিছু ভাঙলে এই পাতা দেখুন। ব্যাকএন্ড ও ডেটাবেসের জন্য `pos_backend/docs/RUNBOOK.md`।

## ১. কোথায় কী চলছে
- সাইট: Netlify, `https://bipone.netlify.app/`। `main`-এ পুশ হলে নিজে বিল্ড ও প্রকাশ হয়।
- বিল্ড সেটিং `netlify.toml`-এ: `npm run build`, প্রকাশ `out/`, Node ২২। নিরাপত্তা হেডার `public/_headers`-এ।
- কোনো গোপন তথ্য ফ্রন্টএন্ডে নেই। একমাত্র ভেরিয়েবল `NEXT_PUBLIC_API_URL` (না দিলে লাইভ API ধরা হয়)।
- **ব্যবহারকারীর ব্যবসার ডেটা সার্ভারে নেই, ফোনের ব্রাউজারে।** তাই ফোনের ব্যাকআপই আসল ব্যাকআপ (নিচে ৪)।

## ২. খারাপ সংস্করণ ছড়িয়ে গেলে (কোড rollback)
**দ্রুততম (১ মিনিট), কোড না ছুঁয়ে:**
1. Netlify → সাইট → **Deploys**।
2. আগের ভালো ডিপ্লয় বাছুন → **Publish deploy**।
3. এতে Netlify নতুন ডিপ্লয় আটকে রাখে (auto-publish বন্ধ)। ঠিক করে পুশ করার পর **Unlock/Start auto publishing** চালু করুন।

**স্থায়ী সমাধান:** `git revert <খারাপ কমিট>` করে `main`-এ পুশ। CI (টাইপ, টেস্ট, বিল্ড) পাস হলে Netlify আবার প্রকাশ করবে।

ফোনে পুরনো পাতা আটকে থাকলে: অ্যাপ পুরো বন্ধ করে আবার খুলুন। সার্ভিস ওয়ার্কার (`public/sw.js`) নতুন সংস্করণ নিজে নেয়। ক্যাশ-কৌশল বদলালে `sw.js`-এর `VERSION` বাড়ান।

## ৩. বিল্ড ফেল করলে
- Netlify → Deploys → ফেল হওয়া ডিপ্লয় → লগ।
- `next/font` বা Google Fonts-এর নেটওয়ার্ক ত্রুটি একবার এসেছিল। আবার চালালে (Retry deploy) সাধারণত পাস করে।
- টাইপ বা টেস্ট ফেল হলে GitHub Actions-এ একই ধাপ ফেল দেখাবে; সেখান থেকে ঠিক করুন।
- `package-lock.json` কমিট করা আছে এবং CI ও বিল্ড `npm ci` চালায়, তাই ডিপেন্ডেন্সির নতুন সংস্করণ হঠাৎ বিল্ড ভাঙায় না। `npm ci` ফেল করলে সাধারণত `package.json` ও লকফাইল মিলছে না: লোকালে `npm install` চালিয়ে লকফাইলসহ কমিট করুন।

## ৪. ফোনের ডেটা (সবচেয়ে গুরুত্বপূর্ণ)
**ব্যাকআপ:** সেটিংস → "ব্যাকআপ ফাইল নামান"। অ্যাপ দিনে একবার (কিছু বদলালে) মনে করায়। ফাইলটি Google Drive বা অন্য ফোনে রাখুন।

**ফেরানো:** সেটিংস → ব্যাকআপ ফাইল বাছুন → নিশ্চিত করুন। শুধু **একই দোকানের** ব্যাকআপ ফেরানো যায়।
- ফেরালে ফোনের বর্তমান ডেটা ব্যাকআপের ডেটা দিয়ে বদলে যায়। আগে এখনকার অবস্থার একটি ব্যাকআপ নিয়ে রাখুন।
- ডিভাইস কোড (A–Z) ব্যাকআপে থাকে না। নতুন ফোনে লগইন করলে সার্ভার নতুন কোড দেবে।

**অ্যাপ ভেঙে গেলে:** ত্রুটি পাতায় "ডেটার কপি নামান" চাপুন। ডেটা নষ্ট থাকলে `pos-raw-তারিখ.json` নামে কাঁচা ফাইল নামবে; সেটি ডেভেলপারকে দিন, ফেরত আনা যাবে।

**ফোন বদল বা মুছে গেলে:** সর্বশেষ ব্যাকআপই একমাত্র ভরসা। সিংক চালু না হওয়া পর্যন্ত এর বাইরে ডেটা ফেরানোর উপায় নেই।

## ৫. ঘটনা ঘটলে প্রথম ১০ মিনিট
1. কী ভেঙেছে? শুধু একটি ফোনে (ডেটা/ব্রাউজার সমস্যা) না সবার (সাইট/API)?
2. সবার ক্ষেত্রে: `https://gaxzkbcomeexlnzquvzf.supabase.co/functions/v1/api/health` ব্রাউজারে খুলুন। `{"status":"ok"}` না এলে ব্যাকএন্ড রানবুক দেখুন।
3. সাইট ভাঙলে ২ নম্বর (Publish deploy)।
4. ব্যবহারকারীকে বলুন: "ডেটা আপনার ফোনে নিরাপদ, ব্যাকআপ নিয়ে রাখুন।"
5. কারণ লিখে রাখুন এবং ঠিক হলে একটি টেস্ট ও কমিট যোগ করুন।

## ৬. যা এখনো যাচাই হয়নি
- রানবুকের Netlify ধাপগুলো ড্যাশবোর্ডের বর্তমান লেখা মিলিয়ে হাতে দেখা হয়নি; লেবেল বদলে থাকতে পারে।
- আসল ফোনে ব্যাকআপ ফেরানোর পুরো ফ্লো একবার চালিয়ে দেখুন।
